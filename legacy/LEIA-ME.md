# Versão 1 (Google Apps Script + Planilha)

Esta pasta guarda a primeira versão do sistema, que funcionava como app da Web do Google Apps Script e gravava os dados numa planilha do Google Drive. Ela foi substituída pela plataforma da raiz do repositório e não recebe mais atualizações.

Para levar os dados dessa versão para a nova, baixe a planilha em **Arquivo → Fazer download → Microsoft Excel (.xlsx)** e siga a seção *Migrar da versão em planilha* do [README](../README.md).
